# kle2c —— 配列（layout）批量转换工具

把 [keyboard-layout-editor.com](https://www.keyboard-layout-editor.com/) 的 **Raw data**
转成固件可直接使用的 C 数组（`KeyLayoutItem`），供上位机按真实配列绘制按键。

## 快速使用

1. 在 KLE 里画好配列，打开 **Raw data** 页签，把内容保存成 `.json`；
2. 把 json 放进 **`layout_json\`** 目录（可放多个，文件名随意）；
3. **双击 `快速转换.bat`**；
4. 结果在 **`output\`**：每个 json 生成一个同名 `.h`，另有汇总 `summary.txt`；
5. 打开对应的 `.h`，把 `const KeyLayoutItem layout_custom[] ...` 整段粘进固件的
   `LayoutManager.h`，替换掉占位布局，重新编译。

命令行等价于：

```bat
python kle2c.py
```

## 按键编号与「错序」

**KLE 不保存按键身份**：Raw data 只是按行排列的位置序列，编号就是它在数组里的先后顺序。
把某个键从第 2 行拖到最底行，它会被序列化到最后，编号随之改变（实测 `#2` 会变成 4 号）。

两种做法：

| 做法 | 说明 |
|---|---|
| **位置编号**（默认） | 编号 = 从上到下、从左到右的顺序。**改完布局必须重新核对**编号与固件 `key_map` 是否一致 |
| **标签编号**（推荐，可抗错序） | 在 KLE 里把每个键的文字写成 `#0`、`#1`…（可放第二行），工具按 `#N` 排序输出，拖动键位后编号不变 |

工具默认 `--index-mode auto`：

* 所有键的标签都带 `#N` → 按标签编号排序，输出注释会写 `Key index: from #N in key labels.`；
* 所有键都没有 `#N` → 按位置编号；
* 只有一部分带 `#N` → **直接报错**，提示补全或去掉。

标签编号必须**正好覆盖 0..N-1**，重复或缺失都会报错，避免贴错表。

显式指定：

```bat
python kle2c.py --index-mode label      :: 强制按 #N，缺失就报错
python kle2c.py --index-mode position   :: 强制按位置
```

## 参数

```text
python kle2c.py                       批量：layout_json -> output
python kle2c.py --dir other --out-dir other_out
python kle2c.py layout.json           单文件：打印到 stdout
python kle2c.py layout.json -o x.h    单文件：写入指定文件
python kle2c.py layout.json --expect 14
python kle2c.py --emit-rotation       额外输出旋转组表（二期）
```

| 参数 | 说明 |
|---|---|
| `--dir` / `--out-dir` | 批量输入/输出目录，默认 `layout_json` / `output` |
| `--array-name` | C 数组名，默认 `layout_custom` |
| `--expect N` | 单文件模式：键数不等于 N 时报错 |
| `--index-mode` | `auto`（默认）/ `label` / `position` |
| `--emit-rotation` | 额外输出 `layout_custom_rotation[]` |
| `--quiet` | 少打印 |

批量模式遇到坏 json 会跳过并继续，最后汇总 `x ok, y failed`，有失败时退出码为 1。

## 单位与顺序

* 坐标单位 **0.25u**：`4 = 1u`，`6 = 1.5u`，`9 = 2.25u`，`25 = 6.25u`；
* 左上角为 `(0,0)`，x 向右、y 向下；
* 坐标不是 0.25u 整数倍时会四舍五入并在 `summary.txt` 里警告。

## flags

| 位 | 含义 |
|---|---|
| bit7..bit6 | `0b11` = 该键需要旋转（角度/中心由 0xFD 帧二期上传） |
| bit5..bit0 | 按键类型：0 普通、1 修饰、2 编码器、3 装饰，4~9 预留 |

工具会自动把 KLE 中 `r != 0` 的键置为 `0xC0`；类型位默认 0，需要时在生成结果里手工改。

## 示例输出

```c
/* Generated by tools/kle2c.py from sixkey.json on 2026-10-19.
 * 6 keys, bounding box 3.00u x 2.00u (12 x 8 units of 0.25u).
 * Key index: from #N in key labels.
 */
const KeyLayoutItem layout_custom[] PROGMEM = {
    {   0,   0,   4,   4, 0x00 },  /*   0: #0         x=0.00u y=0.00u w=1.00u h=1.00u */
    ...
};
```

## 注意

* 注释里的按键文字只作对照；固件不存文字，界面键名由上位机决定。
* 旋转目前只置标志位，角度与旋转中心在 `--emit-rotation` 输出的表里，二期再用。
* 每个输出文件都叫 `layout_custom`，一次只粘贴一个配列到固件。
